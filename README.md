# Journeyman

Is a Copilot CLI plugin that helps you to generate code, documentation, and tests for your project. It uses the power of Copilot to understand your project and generate relevant code snippets.

It is inspired by [Anvil](https://github.com/burkeholland/anvil)

## Agent workflow

This plugin includes two agents:

- `journeyman-plan` for planning-only work.
- `journeyman` for implementation work.
